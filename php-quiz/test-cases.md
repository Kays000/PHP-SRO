# Тестовые сценарии

Автоматические проверки: `php tests/run_tests.php` (63 проверки функций). Сценарии с веб-запросами (доступ, CSRF, повторная отправка, таймер) я проверял вручную в браузере по таблице ниже.

| Категория | Сценарий | Ожидаемый результат | Как проверено |
|---|---|---|---|
| Обычный сценарий | Ввести имя, ответить на все 20 вопросов верно, завершить | 20 из 20, «Отлично», разбор по каждому вопросу | вручную |
| Обычный сценарий | Текстовый ответ в другом регистре и со скобками (`ECHO`, `session_start()`) | Засчитывается | автотест |
| Пустые значения | Пустое имя или одни пробелы | Сообщение об ошибке, тест не начинается | автотест, вручную |
| Пустые значения | Вопрос оставлен без ответа | 0 баллов за вопрос, в отчёте «нет ответа» | автотест |
| Граничные значения | Имя из 1, 2, 50, 51 символа | 1 и 51 отклоняются, 2 и 50 принимаются | автотест |
| Граничные значения | Текстовый ответ из 100 и 101 символа | 101 отклоняется | автотест |
| Граничные значения | Номер вопроса `0`, `21`, `-1`, `abc` в адресе | Показывается допустимый вопрос, ошибки нет | автотест, вручную |
| Граничные значения | Оценка на порогах 90, 89.9, 75, 74.9, 60, 59.9 % | Верная оценка | автотест |
| Некорректный тип | Массив вместо строки (имя, ответ на вопрос с одним вариантом) | Сообщение об ошибке, состояние не меняется | автотест |
| Некорректный тип | Строка вместо массива в вопросе с несколькими вариантами; несуществующий вариант | Сообщение об ошибке | автотест |
| Некорректный тип | `<script>` в имени | Имя отклоняется | автотест |
| Повторная отправка | Нажать «Завершить тест» второй раз или обновить страницу результата | Дубля в `results.json` нет | автотест (`save_result` дважды), вручную |
| Доступ | Открыть результат в другом браузере по ссылке | Ошибка 403 | вручную |
| Доступ | В адресе `result.php?id=...` подставить чужой или неверный id | 403 или переход на главную | вручную |
| CSRF | Отправить форму без токена или с неверным токеном | Ошибка 403 | автотест, вручную |
| Хранилище | `results.json` или `questions.json` повреждён | Страница «Данные временно недоступны», без технических подробностей | автотест, вручную |
| Хранилище | В `questions.json` правильный ответ вне списка вариантов | Ошибка загрузки вопросов | автотест |
| Время | Запустить с `QUIZ_TIME_LIMIT=20` и подождать | Тест завершается сам, в отчёте «завершён по времени» | вручную |

## Найденные при разработке ошибки

- Формы отправлялись без CSRF-токена (шаблоны его не получали), из-за этого все запросы отклонялись с ошибкой 403. Исправлено.
- В тесте вопрос с несколькими ответами отправлялся как `answer=1&answer=3` вместо `answer[]=1&answer[]=3`, и сервер правильно отклонял такой запрос. Тест исправлен, код приложения менять не пришлось.
