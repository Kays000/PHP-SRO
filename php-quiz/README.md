## О проекте

Веб-приложение для прохождения теста по основам PHP. Вопросы берутся из JSON-файла, в конце приложение считает баллы и показывает разбор: что я ответил, как правильно и почему. Всё написано на чистом PHP, без фреймворков и базы данных.

## Что умеет приложение

- Банк из 44 вопросов. В каждой попытке 20 случайных вопросов в случайном порядке.
- Три типа вопросов: один вариант ответа, несколько вариантов, короткий текстовый ответ.
- Ответы хранятся в сессии. К любому вопросу можно вернуться и изменить ответ.
- Подсчёт баллов и разбор ошибок выполняют функции: правильный ответ, мой ответ, пояснение и номер лекции.
- Повторная отправка не создаёт дубль: после формы выполняется редирект, а результат в JSON записывается по id попытки.
- **Повышенная сложность:**
  - ограничение времени (20 минут), таймер на странице, автозавершение на сервере;
  - сохранение промежуточного состояния: можно закрыть вкладку и продолжить попытку в той же сессии.
- Страница «Мои попытки» со списком результатов текущей сессии.

Каждый вопрос стоит 1 балл. В вопросах с несколькими вариантами балл дают только за полностью верный ответ. Оценка: от 90% «Отлично», от 75% «Хорошо», от 60% «Удовлетворительно», ниже — «Неудовлетворительно».

## Установка и запуск

### XAMPP

1. Скопировать папку проекта в `C:\xampp\htdocs\php-quiz`.
2. Запустить Apache в XAMPP Control Panel.
3. Открыть http://localhost/php-quiz/

Папка `data` должна быть доступна для записи: туда сохраняется `results.json`. Файл создаётся сам при первом завершённом тесте.

### Тесты

```bash
php tests/run_tests.php
```

Описание сценариев — в [test-cases.md](test-cases.md).

### Настройки

В начале `includes/functions.php`: `QUESTIONS_PER_TEST` (вопросов в попытке) и `TIME_LIMIT` (секунд на попытку). Чтобы проверить таймер, можно запустить так: `QUIZ_TIME_LIMIT=20 php -S localhost:8000` (в PowerShell: `$env:QUIZ_TIME_LIMIT=20; php -S localhost:8000`).

Формат вопроса в `questions.json`: `type` (`single`, `multiple` или `text`), `text`, `options` (список вариантов), `correct` (номер варианта, список номеров или список допустимых текстовых ответов), `explanation`, `lecture`.

## Безопасность и валидация

- В каждом PHP-файле `declare(strict_types=1)`, у функций указаны типы.
- Всё, что приходит от пользователя, проверяется на сервере: имя (длина, символы), ответ (тип, допустимые варианты, длина), номер вопроса.
- Динамический текст перед выводом экранируется через `htmlspecialchars()` (функция `e()`).
- Изменения выполняются только через POST и защищены CSRF-токеном (сравнение через `hash_equals`).
- Cookie сессии с флагами `HttpOnly` и `SameSite=Lax`, после начала теста вызывается `session_regenerate_id(true)`. В cookie нет данных теста.
- Результат можно открыть только в своей сессии: id попыток лежат в `$_SESSION`.
- Запись в JSON выполняется под блокировкой `flock`. Повреждённый файл или недоступная папка дают понятное сообщение без технических подробностей (они пишутся в лог).
- Папки `data`, `includes`, `tests` закрыты через `.htaccess` для Apache.

## Тестирование

Проверяются обычный, ошибочный и граничные сценарии: пустые поля, массив вместо строки, неизвестный вариант ответа, имя из 1/2/50/51 символа, повторная отправка, чужой результат, запрос без токена, повреждённый JSON, завершение по времени. Подробности и найденные ошибки — в [test-cases.md](test-cases.md).

## Ограничения и развитие

- Нет учётных записей: результаты привязаны к сессии браузера.
- Встроенный сервер `php -S` не читает `.htaccess`, поэтому при таком запуске файлы из `data/` можно открыть по прямой ссылке. Для настоящего экзамена нужен Apache или перенос `data/`  
- Данные хранятся в JSON. После изучения PDO их можно перенести в базу данных, а после ООП оформить вопросы и попытки как классы.
- Идеи: перемешивание вариантов ответа, частичные баллы, роль преподавателя со статистикой.
